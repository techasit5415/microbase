# Microbase

**Microbase** is a self-hosted, single-binary Backend-as-a-Service (BaaS) inspired by PocketBase and powered by **PostgreSQL** (`pgvector`), **Go (Echo v4)**, optional **Redis**, **S3-compatible object storage**, and an embedded **SvelteKit 3 + Svelte 5** Admin Dashboard (`/_/`).

## Key Features

- **Single Binary Deployment**: Embedded Admin Dashboard (`go:embed`), zero runtime Node.js required.
- **Dynamic PostgreSQL Collections**:
  - **Base collections** (`CREATE TABLE`), **View collections** (`CREATE OR REPLACE VIEW`), and **Auth collections** (including customizable `users`).
  - **17 Field Types**: `text` (with regex validation & `autogenerate_pattern`), `editor`, `number`, `integer`, `float`, `boolean`, `email`, `url`, `datetime`, `autodate`, `file`, `relation` (real PostgreSQL Foreign Keys), `select`, `json`, `geopoint`, and `vector` (`pgvector`).
  - **Flexible Primary Keys**: PocketBase-style autogenerated string IDs (`[a-z0-9]{15}`, `uuid`, custom patterns) or `BIGSERIAL`.
  - **Unique Constraints & Composite Indexes**: Real PostgreSQL `CREATE [UNIQUE] INDEX` management.
- **Rich REST & Realtime API**:
  - Full PocketBase-style `?filter=...` expression parser (`=`, `!=`, `>`, `>=`, `<`, `<=`, `~`, `!~`, `&&`, `||`, parentheses, `@request.auth.*`).
  - `?expand=...` relation expansion, `?fields=...` projection, English FTS + Thai `ILIKE` search, `pgvector` cosine similarity search, SSE Realtime (`/api/realtime`), and Batch API (`POST /api/batch`).
- **Authentication & Security**:
  - First-run **8-digit 5-minute Setup OTP** printed in server logs; `/api/superusers/setup` locks permanently once the first superuser is created.
  - Argon2id password hashing, JWT authentication, Refresh, Email Verification, Password Reset, Email Change, 6-digit Email OTP, MFA, and Superuser Impersonation.
  - **OAuth2 & OIDC**: Google, Discord, Standard OIDC auto-discovery, and Custom IAM endpoints with JSON dot-path Claim-to-Column mapping.
  - **Secure-by-default API Rules**: Every collection rule is locked to `_superusers` until explicitly unlocked.
- **Storage, Caching & Operations**:
  - **Hot-swappable S3 Storage** (AWS S3, Cloudflare R2, MinIO) + on-the-fly `?thumb=WxH` image resizing.
  - **Hot-swappable Redis Cache** configurable at runtime from Settings without restarting.
  - **Outbound Notification Hooks**: Discord Embeds, Firebase FCM HTTP v1, and Generic HTTP webhooks.
  - **Built-in Admin Tools**: SQL Console, ERD Schema viewer, Persistent PostgreSQL Logs (`_logs`) with chart, SMTP Mail, `pg_dump` Backups & Restore, Cron Jobs, Per-Route Rate Limits, and Schema Export/Import JSON.

## Quick Start

```bash
# 1. Start PostgreSQL (with pgvector)
docker compose up -d

# 2. Configure environment variables
cp .env.example .env
# Edit .env and set DATABASE_URL and a strong JWT_SECRET

# 3. Build Frontend & Single Go Binary
cd ui && npm install && npm run build && cd ..
go build -ldflags="-X github.com/techasit5415/microbase/internal/config.Version=v0.10.32" -o microbase ./cmd/server

# 4. Run Microbase
./microbase
```

On first launch (when `_superusers` is empty), Microbase prints a one-time **8-digit Setup OTP** (valid for 5 minutes) in the server terminal. Open `http://localhost:3000/_/` to create your first Superuser account.
